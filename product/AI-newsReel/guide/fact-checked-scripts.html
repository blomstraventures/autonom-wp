Fact-Checked AI Scripts:
How to Write News Shorts Without Inventing Facts

An AI model asked to write a news script will produce one. It will be fluent, it will have a hook, and it will sound like a wire reporter. What it will not do is check a single number against the article it came from. That is not a flaw you can prompt away. Fluency is what the model was trained for; verification is a separate process that has to be built around it, with code that refuses to move on when the quote is not in the source.

This guide is about that process. What most tools skip, what a script that ties every claim to a quote actually looks like, and the five checks you can run on any AI news tool before you publish from it.

⚠
AI that never invents facts is a process, not a model.

No model is reliable enough to trust on its own. What makes a script trustworthy is the chain around it: every fact carries an exact quote, the quote is checked against the article, and a script that fails the check is sent back rather than published.

What most AI script tools actually do

There are three shapes most AI news tools fall into. None of them is dishonest on purpose. They are all the same compromise: it is easier to produce a script than to prove one.

1. The fluent summarizer

Give it the article, ask for a 60-second script. It reads, compresses, and writes. The output is readable and mostly right. What it does with the parts it is less sure of is invisible: a figure of "up to 40%" becomes "40", a date gets rounded, a quote gets paraphrased into something the speaker did not say.

What actually happens: The script ships. It is wrong in one place, which is enough. The audience has no way to know which sentence is the wrong one, so the credibility of every sentence goes with it.

2. The headline paraphraser

Many tools only reliably get the headline, the first paragraph, or a search snippet — the rest of the page is behind a paywall, or rendered in JavaScript the tool cannot read. So the script is built from what was visible, and the body that contradicts the headline never gets read.

What actually happens: The script repeats the framing the editor already decided, without the detail that qualifies it. It sounds confident and it is thinner than the reader thinks.

3. The template filler

A hook, a body, a call to action. Three slots, each filled with something plausible. "This development could have significant implications." "Analysts say the move signals a shift." Nothing in those sentences is checkable, which is exactly the problem: there is nothing to be wrong about, and nothing to be right about either.

What actually happens: The channel publishes volume, the audience learns nothing, and after a few weeks the format stops being watched.

How fact-checked scripts work

A fact-checked script is not written; it is assembled, then audited. The model still writes, but every sentence has to survive a chain of checks that sits between the draft and the publish button. This is the chain Autonom Newsreel runs, step by step, at a high level. Nothing here requires code to understand.

  1. Read the article. Not the headline, not the RSS description — the full text of the article page. If the page cannot be read (paywall, live blog, video page), the story is skipped. A script without a readable source is a guess with better grammar.
  2. Extract facts, each with a quote. The model reads the article and returns 8–12 facts. Each one is two things: a one-sentence claim in plain words, and an exact quote copied from the article that proves it. No quote, no fact.
  3. Check every quote against the article. This is done by code, not by the model. Normalize the whitespace and punctuation of both, then ask: does this quote appear in this article, word for word? If it does not, the fact is dropped. A model that hallucinated a quote cannot survive this step, because the article is the referee.
  4. Check every claim against its quote. A quote can be real and still be misused. "Up to 45%" can become "45%". "The minister said he was considering" can become "the minister announced". A second pass — code for numbers and qualifiers, then a model check for meaning — drops or rewrites any fact whose claim says more than the quote supports.
  5. Look for a second outlet. The tool searches open publisher feeds for another outlet reporting the same event. If it finds one, it reads that article and compares it against the first, fact by fact. Each fact comes out tagged: confirmed by both, only the first outlet reports this, or the two outlets differ. On a story where the second outlet cannot be found, every fact is tagged single source, and the script has to say so.
  6. Write the script from the tagged facts. Now the model writes. But it writes only from the facts that survived, and it sees the tags. It is told which facts it can state as fact, which it has to attribute to a named outlet, and which to leave out because the two outlets disagree.
  7. Check the script against the article. Numbers in the script must appear in the article. Capitalized names must appear in the article. Qualifiers have to be preserved — "up to", "around", "reportedly" cannot be dropped. Words that make a claim stronger than the source ("effectively", "crippled", "collapse", "solely") are flagged. Forecasts the source did not make ("will", "is likely to") are flagged. Attribution to "analysts" or "experts" the source never mentioned is flagged.
  8. Audit every sentence. Finally, a model reads the script sentence by sentence against the quotes and flags what it finds: a sentence that says more than the quote, a cause the source did not state, an inference presented as a fact, a hedge that went missing. Each flagged sentence comes back with a suggested fix. If more than one needs fixing, the script is rewritten once, re-checked, and re-audited. If it still fails, it is shown to the human with the flags attached, not published.

What to check in any AI script tool

You do not need to build this pipeline yourself. But before you trust any AI news tool — including this one — run five checks. They take twenty minutes and they separate tools that verify from tools that produce.

  1. Does it show you the quote? For every fact in the script, ask the tool to show the sentence from the article that proves it. If it cannot, it has no proof — it has a summary. A tool that shows you the quote is not being generous with its work; it is showing you the check. The absence of that check is the whole story.
  2. Does it tell you what the second outlet says, not just "verified"? "Verified by two sources" is a badge; it is not a fact. Ask which outlet, and ask what each outlet actually said. Real corroboration produces tags — both, first only, they differ — not a label. If the tool cannot tell you which outlet disagrees with which, it is not doing corroboration; it is doing a search. The source quote verification guide goes deeper on this check.
  3. Does it keep the qualifiers? "Up to 45%" and "45%" are different claims. "Around 80%" and "80%" are different claims. "Reportedly" and nothing are different claims. Open the script and search for up to. If the hedges have all been sanded off in favor of a cleaner sentence, the tool has already made an editorial choice you did not authorize.
  4. Does it name who said what? A source that rests on a government claim, a military statement, or a party to a conflict has to attribute it — in the sentence, not in a footnote. If a script says "the strikes hit a hospital" without saying who reported it, it has taken a side. If it says "analysts say" without naming one, it has invented a source.
  5. Does it show you what it dropped? Good tools keep a record: facts it could not verify, claims it had to rewrite, sentences the audit removed. The dropped material is where the interesting edits happen. A tool that shows you only the finished script and none of its working is asking you to trust a process you cannot see.
✓
The five-minute test.

Open the script, search for %, and check every percentage against the source. Then search for will and could, and check that each forecast is a forecast the source made. That is the whole audit in five minutes; the pipeline above does it in five seconds.

None of these checks requires you to read the article twice. They require the tool to be designed around showing its work, which is a product decision, not a model decision. A tool built this way will not be faster than one that isn't. It will be the one you can put your name on. The EU has set tariffs of up to 45% on Chinese electric vehicles, according to the European Commission. Brussels says the duties respond to state support that gave Chinese makers an unfair advantage. China has said it will challenge the decision at the World Trade Organization. Whether the tariffs hold depends on whether Brussels can keep member states united if Beijing retaliates against European exports.

The first version is more fun. It is also wrong in four places: the rate was "up to 45%", not a flat 45%; "unfair subsidies" is Brussels's characterization, not a finding; "will force" is a forecast no one made; and "the trade war everyone saw coming" is a caption for a different story. The second version is slower to read and says what the source says. That is the whole trade.

Frequently asked questions

Can AI write a news script without inventing facts?

Not on its own. A model asked to write a news script will sometimes add a plausible-sounding detail that was not in the source. What makes a script safe is the process around the model: extract with quotes, verify the quotes against the article, verify the claims against the quotes, and rewrite anything that fails. The model is a writer; the checks are what make the writing trustworthy.

What does "fact-checked" actually mean in an AI script tool?

It should mean at least three things: every claim in the script is tied to an exact quote in a source, the quote was checked against the article (not just taken on the model's word), and the claim says no more than the quote. If a tool uses the phrase and cannot show you the quote, the phrase is marketing. Ask the tool to show its work — the quotes, the tags, and the sentences the audit removed.

Do I still need to review an AI script before publishing?

Yes. The pipeline catches what a machine can catch: an invented quote, a number that is not in the source, a hedge that went missing, a forecast the source did not make. It cannot catch a source that is wrong, an angle you disagree with, or a framing that is technically supported and still misleading. Read every script once before you publish. The tool shortens that read; it does not remove it.

What happens when the source article is wrong?

The script will repeat the error, accurately attributed. This is a limit worth stating plainly: no fact-checking pipeline can verify the article itself. If a publisher reports a number that later turns out to be wrong, the script is wrong in the same place, with a quote that proves where it came from. That is why the tool shows you the source, why a second outlet matters, and why the human read is still on you.

How long does fact-checking a script take?

Longer than writing one without checks, which is the point. On a free API tier, plan on one to two minutes per story. Most of that is the model writing the script and the audit reading it back. The code checks (quotes, numbers, names, qualifiers) are instant. If you are publishing a handful of videos a day, the time is well spent: a script you have to rewrite costs more than a script you waited for.

Does fact-checking work for non-English sources?

Today, Autonom Newsreel is English-only. The pipeline is language-agnostic in principle — the quote check is string comparison, the claim check is a model reading in whatever language it was given — but the prompts, the feeds, and the voice are all English. If you are working in another language, check whether the tool you are using supports it; do not assume the same checks apply.
