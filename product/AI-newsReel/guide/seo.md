## Verification checklist

Run once per page after pasting into AIOSEO. All eight should be true.

- [ ] **Focus keyphrase** pasted exactly, all lowercase, no trailing space
- [ ] **SEO title** — AIOSEO character counter shows green (≤60 characters). The focus keyphrase or a close variant appears in the title
- [ ] **Meta description** — counter shows green (≤155 characters). The focus keyphrase appears in the meta description
- [ ] **H1** matches the H1 in the page body. AIOSEO warns if it does not
- [ ] **Preview snippet** — open the "Preview snippet" tab, check the result looks right on desktop **and** mobile
- [ ] **Enable AIOSEO for this post** toggle is on (easy to miss)
- [ ] **Sitemap inclusion** — confirm the page is not excluded from the sitemap in AIOSEO's Sitemap tab
- [ ] **Indexing** — the page is not set to `noindex` and is not blocked by a robots rule

## Publishing order

Google treats a batch of new pages from the same site on the same day as lower-priority than a steady cadence. Publish one or two pages per day.

| Day | Pages |
|---|---|
| 1 | Hub `/guide/` (add the AI News to Shorts section) + Pillar `/guide/ai-news-to-shorts/` |
| 2 | Spoke 1 + Spoke 2 |
| 3 | Spoke 3 + Spoke 4 |
| 4 | Spoke 5 + Spoke 6 |
| 5+ | Run Rich Results Test on all 8 URLs, then submit the full set as one sitemap entry in Google Search Console |

The pillar must be indexed **before** the spokes get submitted. The pillar is the hub that links to all six spokes, so indexing it first means the spokes inherit the pillar's link equity when they land.

## Post-launch sanity checks

Run these after the site is live and indexed.

- Open each of the 8 URLs in a browser and confirm the H1 on the page matches the H1 in this document.
- View source → `Ctrl+F` → `application/ld+json`. Confirm two JSON-LD blocks per page: one `Article`, one `FAQPage`.
- In the `FAQPage` block, count occurrences of `"@type": "Question"`. Should be **6** for each spoke and **9** for the pillar.
- Open [search.google.com/test/rich-results](https://search.google.com/test/rich-results) and paste each URL. Confirm 0 errors, and confirm both **Article** and **FAQPage** appear in the detected types list.
- Open [search.google.com/search-console](https://search.google.com/search-console) → URL Inspection → for each new URL, request indexing. Do not submit more than 2 per day.
- After 7–10 days, check Coverage → Pages in Search Console and confirm all 8 URLs are indexed with no errors.

## Notes

- The pillar's SEO title drops the "fact-checked video" phrasing to fit under 60 characters, but the meta description keeps it. The pillar's H1 already carries the "fact-checked" phrase, so search results will show it in the title tag of the SERP snippet anyway via the H1 rich snippet.
- Spoke 1's SEO title is the longest in this set (59 characters). Do not add anything to it — one more character and Google truncates it mid-word on desktop SERPs.
- Spoke 4's focus keyword is `post youtube shorts to instagram`, which is a longer, more specific query than `publish shorts everywhere`. The guide covers both, but the ranking target is the specific one — the broader phrase is captured by the pillar and by spoke 3.
- Do not change AIOSEO values after publishing unless you are also updating this document. The values here and the values in the live AIOSEO fields must match, or a future SEO audit will flag a mismatch.
