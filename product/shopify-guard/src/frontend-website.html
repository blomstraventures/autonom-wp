Why Shopify CSV imports break live stores

The Shopify importer is designed to update existing products. That's what makes it useful. It's also what makes it dangerous. A CSV can pass syntax validation and still silently clear prices, drop variants, or overwrite descriptions.

⚠

Blank cells clear live data

If you include a column like Variant Price but leave cells empty, Shopify treats the blanks as intentional overwrites. Existing products with matching handles may have their prices cleared.

⚠

Handles overwrite quietly

Shopify matches rows to products by Handle. A matching handle means every included column in that row replaces the live value.

⚠

Variants disappear silently

If a product has three variants in your store but the CSV only includes one, Shopify may delete the other two. No warning. No undo.

Three tiers of repair — and complete transparency

Autonom separates every issue into one of three classes. The distinction matters because it tells you exactly what changed, and what didn't.

Safe

Automatic fixes

Deterministic corrections that cannot lose information. Applied without asking, listed in the change log.

  • BOM and encoding fixes
  • Smart quote replacement
  • Whitespace trimming
  • Currency symbol stripping
  • Handle normalization
Review

Fixes that need your approval

Changes that might collide with your conventions. Each has a checkbox, a preview, and a plain-language reason.

  • Handle generation from titles
  • HTTPS upgrades
  • HTML tag repair
  • File splitting for oversized CSVs
  • Duplicate SKU suffixing
Flagged

What Autonom will not change

Missing values, ambiguous data, and things that require your judgment. We flag them — we never invent them.

  • Missing product titles
  • Non-numeric prices
  • Orphaned variants
  • Invalid status values
  • Dangerous HTML tags

Frequently asked questions

Is my file uploaded to Autonom?

No. Everything runs in your browser. Your CSV is never sent to a server. You can verify this in your browser's DevTools Network tab.

Is this free?

Yes. Every feature is free. No account. No paywall. No watermark.

Does Autonom connect to my Shopify store?

No. Autonom never connects to your Shopify store. It generates a corrected file you choose to import yourself.

Can Autonom guarantee my import will succeed?

No. We don't know your store's current data. We check what we can check and tell you what we can't.

What happens if my file is over 15 MB?

Autonom splits it into parts under Shopify's limit. Products stay whole — all variant rows of the same Handle go into the same part.

What if my file uses semicolons instead of commas?

Autonom detects it and offers a one-click conversion. This is common with European Excel exports.

What is a destructive blank?

A blank cell in a column you've included. Shopify treats blanks in included columns as intentional overwrites. Autonom flags them before you import.

Does Autonom modify my Shopify store?

No. Autonom never connects to your store. It generates a corrected file you choose to import yourself.

What file types are supported?

CSV files in Shopify's product export format. Up to 50 MB.

Can I use this on my phone?

Yes. It works in all modern mobile browsers.

How is this different from Shopify's built-in preview?

Shopify's preview runs after you click import. Autonom runs before, on your local machine, with a broader set of checks — including destructive blanks, variant inconsistencies, and file size handling.

Will Autonom fix my file or just tell me what's wrong?

Both. Safe fixes are applied automatically. Review-required fixes need your approval. Issues that would require inventing data are flagged for you to fix in the source.
