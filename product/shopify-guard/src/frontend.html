Why Shopify CSV imports break live stores

Shopify's built-in CSV importer validates structure. It confirms that your file has the right headers and that each row has the right number of columns. What it does not do is warn you when a syntactically valid file would silently change or delete live product data.

The Shopify documentation warns about this. If you include a column in your CSV, Shopify treats every cell in that column — including blank cells — as an instruction. A blank cell in an included column is not "no change." It is "clear this field."

This single design decision is responsible for most of the worst CSV import disasters merchants report. Prices disappear. Descriptions vanish. Variants get deleted. And the merchant only discovers it days later when a customer complains.

The three failure modes merchants report most often

1. Blank values in included columns clear live data

If you include a Variant Price column but leave cells empty, Shopify treats the blanks as intentional overwrites. Existing products with matching handles may have their prices cleared.

See Shopify documentation →

2. Matching handles overwrite matching columns

Shopify matches imported rows to existing products by the Handle column. If a row's handle matches an existing product, Shopify replaces values in every column included in the file.

See Shopify documentation →

3. Missing variant data silently deletes variants

If a product has multiple variants in your store but the CSV only includes one variant row for that handle, Shopify may delete the missing variants.

See Shopify documentation →

What Autonom Shopify Guard checks

Autonom runs more than thirty validation rules. Each issue falls into one of three categories: critical (will break the import or damage live data), warning (degrades quality), or info (context).

Structure, identity, and handles

  • Missing or duplicate column headers
  • Unknown columns Shopify will ignore
  • Missing handles in update mode
  • Duplicate handles across different products
  • Handles with uppercase, spaces, underscores, or accents

Variants

  • Variant rows without a parent handle
  • Duplicate option combinations
  • Incomplete option pairs
  • Inconsistent option names across the same product
  • Single-variant products with multiple images but no Option1 declaration

Prices, inventory, and SKUs

  • Non-numeric, negative, or currency-symbol prices
  • European comma-decimal prices
  • Compare-at price lower than price
  • Non-integer or negative inventory
  • Inventory tracker mismatch
  • Duplicate SKUs, whitespace in SKUs

Content and encoding

  • UTF-8 byte-order marks
  • Non-UTF-8 encoding
  • Smart quotes, em-dashes, ellipses from Word
  • Unclosed HTML tags and dangerous tags
  • Non-standard boolean values
  • Product Category format mismatches

Images

  • HTTP image URLs
  • Private CDN or localhost URLs
  • URLs without image extensions
  • Duplicate image rows
  • Image rows with stray variant data

File-level

  • Semicolon or tab delimiters instead of commas
  • Duplicate identical rows
  • Files approaching or exceeding Shopify's 15 MB limit (with automatic splitting)

What Autonom fixes, flags, and refuses to touch

Safe automatic fixes

  • UTF-8 byte-order mark removal
  • Encoding conversion to UTF-8
  • Smart quote replacement
  • Whitespace trimming
  • Currency symbol stripping
  • Boolean format normalization
  • Handle normalization
  • Duplicate image row removal

Review-required fixes

  • Generating handles from product titles
  • Upgrading HTTP image URLs to HTTPS
  • Repairing unclosed HTML tags
  • Converting comma decimals to dot decimals
  • Clearing stray variant data from image rows
  • Setting Option1 for single-variant products with images
  • Defaulting missing inventory quantities to 0
  • Suffixing duplicate SKUs
  • Removing a column where 30%+ of cells are blank
  • Splitting oversized files into importable parts
  • Converting semicolon or tab delimiters to commas

What Autonom will never change

  • Missing product titles
  • Missing handles in update mode
  • Duplicate handles with different titles
  • Orphaned variant rows
  • Non-numeric prices
  • Negative prices or inventory
  • Invalid status values
  • Private CDN image URLs
  • Dangerous HTML tags

Your CSV never leaves your browser

Autonom processes everything locally using the browser's FileReader API. Your file is parsed in memory, validated on your device, and packaged into the output ZIP without any network requests.

You can verify this yourself. Open DevTools, watch the Network tab during a scan, and you will see zero outbound requests for your CSV.

How to check your Shopify CSV in four steps

1. Export or prepare your CSV

Use a supplier-provided CSV, a Shopify export, or a hand-edited spreadsheet saved as CSV.

Frequently asked questions

Is my Shopify CSV uploaded to Autonom?

No. Autonom processes your CSV entirely in your browser. Your file contents are never transmitted to Autonom's servers.

Is this tool free?

Yes. The readiness report, the corrected CSV, and all repairs are free. No account required. No watermark.

How does Autonom know if I'm adding new products or updating existing ones?

Autonom inspects the columns in your file. Shopify exports typically include Status, Published, and Image Position. When those appear, we suggest update mode. You can override.

Can Autonom guarantee my import will succeed?

No. Autonom does not know your store's current data and does not connect to your Shopify store. We check what we can check and tell you what we cannot.

What happens if my file is over 15 MB?

Autonom detects the size, flags it as critical, and can split the file into multiple parts — each under the limit. Products stay whole: all variant rows of the same Handle stay in the same part.

What if my file uses semicolons instead of commas?

Autonom detects the delimiter and offers a one-click conversion to comma-separated values. This is common with European Excel exports.

What is a destructive blank?

A blank cell in a column you have included. Shopify treats blank cells in included columns as intentional overwrites. If the row matches an existing product, the field will be cleared.

Does Autonom modify my Shopify store?

No. Autonom never connects to your Shopify store. It generates a corrected file. You choose whether to import it.

What file types are supported?

CSV files in Shopify's product export format. Up to 50 MB.

Can I use this on my phone?

Yes. Autonom works in all modern mobile browsers. The report is easier to read on a larger screen.

How is this different from Shopify's built-in preview?

Shopify's preview runs after you click import. Autonom runs before, on your local machine, with a broader set of checks — including destructive blanks, variant inconsistencies, and file size handling.

Will Autonom fix my file or just tell me what's wrong?

Both. Safe fixes are applied automatically. Review-required fixes need your approval. Issues that would require inventing data are flagged for you to fix in the source.
