Why Shopify CSVs are dangerous

Shopify's CSV importer is designed to update existing products. That's what makes it useful. It's also what makes it dangerous. A CSV can pass Shopify's syntax validation and still silently overwrite your live product data.

Three ways a valid CSV can damage your store

1. Blank values in included columns

If you include a column like "Variant Price" but leave its cells empty, Shopify treats the blank cells as intentional overwrites. Any existing products with matching handles may have their prices cleared.

See Shopify documentation →

2. Matching handles update matching columns

Shopify matches imported rows to existing products by the Handle column. If a row's handle matches an existing product, Shopify will replace values in every column included in the file.

See Shopify documentation →

3. Missing variant columns can delete variants

If a product has multiple variants in your store but the CSV only includes one variant row for that handle, Shopify may delete the missing variants.

See Shopify documentation →

Frequently asked questions

Is my file uploaded to Autonom?

No. Shopify Guard processes your CSV entirely in your browser using JavaScript. Your file contents are never transmitted to Autonom's servers.

Is this free?

Yes, the readiness report is fully free. You can see every issue we detect, download the report, and share it.

How does Autonom know if I'm adding or updating products?

Autonom inspects the columns in your file. Shopify exports typically include columns like Status, Published, and Image Position — when we see those, we suggest "Updating existing products." You can always override our suggestion.

Can Autonom guarantee my import will succeed?

No. Autonom does not know your store's current data, and we do not connect to your Shopify store. We check what we can check and tell you what we can't.

What file types are supported?

CSV files only (Shopify product export format). Maximum size is 50MB.

Will Autonom automatically change my data?

No. Autonom never modifies your store. It only generates a corrected CSV file that you choose to import or discard.
